# 墨流 InkFlow

本地运行的 macOS 拼音输入法，支持全拼、简拼、中英混输、Emoji 候选和简繁切换。

需要 **Apple Silicon Mac，macOS 26 或更新版本**。

## 安装与启用

1. 从 [下载页面](https://github.com/nervouna/InkFlow/releases/latest) 下载并打开 `.dmg` 文件。
2. 在 Finder 按 `Shift + Command + G`，前往 `~/Library/Input Methods/`。若不存在，在 `~/Library/` 下新建 `Input Methods` 文件夹。
3. 将 `InkFlow.app` 复制到该文件夹，推出磁盘映像，然后注销并重新登录 Mac。
4. 打开「系统设置 → 键盘 → 文字输入 → 编辑」，点按 `+`，添加「墨流拼音」（英文系统为 **InkFlow Pinyin**）。
5. 从菜单栏输入菜单选择「墨流拼音」。输入 `nihao`，按空格选出「你好」。

## 日常输入

试试 `hulianwang`、`hlw` 或 `hulw` 输入「互联网」，`bs` 输入「不是」。中文模式中也能选择英文词和 Emoji；需要原样输入任意英文时，切换到英文模式。

| 操作 | 按键 |
| --- | --- |
| 选择候选 | 空格、候选旁的数字，或鼠标点击 |
| 上一页／下一页 | `[` / `]` 或 `Page Up` / `Page Down` |
| 删除正在输入的字母 | 退格 |
| 取消当前输入 | `Esc` |
| 提交原始输入字母 | 回车 |
| 切换中文／英文 | `Control + Shift + Space` |

输入菜单也可切换中英文，并勾选「英文标点」或「繁体输入」。正在输入时，更改会在本次输入完成或取消后生效。

## 设置

选中墨流后，从输入菜单选择「打开设置」。设置自动保存。

- **外观**：调整候选词方向、数量和字号。
- **输入**：简拼、自动纠错和 Emoji 默认开启，模糊音默认关闭。可在 `[]` 与 `-=` 中选择一组翻页键，调整特殊标点映射，或开启英文标点、繁体输入。英文标点会暂停特殊映射；繁体输入保留自定义短语原文。输入偏好在本次输入完成或取消后生效。
- **个性化**：点击「添加」，输入码填 `dz`、短语填「台北市信义区」，点击「保存」。以后输入完整的 `dz` 即可优先选出地址。输入码使用英文字母，短语需为单行文字；修改在当前输入结束后生效。
- **词库**：点击「检查词库更新」，发现更新后点击「下载并更新」。更新需要联网，并在所有正在进行的输入结束后启用；部分内置词条随应用更新。

## 更新应用

切换到其他输入法并保存工作，备份 `~/Library/Input Methods/InkFlow.app`，再用新下载的 `.dmg` 中的应用替换。注销并重新登录即可，无需重新添加输入源。若提示应用正在使用，先注销，再用其他输入法登录后替换。

保留 `~/Library/Application Support/InkFlow` 中的用户词典和数据。

## 本地数据

日常输入离线完成。用户词典、自定义短语和输入质量记录均保存在本机，不会上传。质量记录默认开启，包括输入内容、候选、选词结果及可获取的光标前文。
