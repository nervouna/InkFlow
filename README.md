# 墨流 InkFlow

本地运行的 macOS 拼音输入法，支持全拼、简拼、中英混输、Emoji 候选和简繁切换，也可自选开启 AI 输入建议。

需要 **Apple Silicon Mac，macOS 26 或更新版本**。

## 安装与启用

1. 从 [下载页面](https://github.com/nervouna/InkFlow/releases/latest) 下载并打开 `.dmg` 文件。
2. 双击「墨流安装器」，点按「安装并启用」，按系统提示完成确认。
3. 安装完成后，从菜单栏输入菜单选择「墨流拼音」。

## 日常输入

| 操作 | 按键 |
| --- | --- |
| 选择候选 | 空格、候选旁的数字，或鼠标点击 |
| 上一页／下一页 | `[` / `]` 或 `Page Up` / `Page Down` |
| 删除正在输入的字母 | 退格 |
| 取消当前输入 | `Esc` |
| 原样提交正在输入的字母 | 回车 |
| 切换中文／英文 | 单击左 `Shift` |

回车会跳过候选转换，原样提交当前字母串，适合输入未收录的项目名或 `getUserName` 这类标识符。需要保留 `_`、`+`、URL、路径或版本号时，请先单击左 `Shift` 切换到英文输入；此时字符直接交给当前应用，不显示候选，也不转换成中文标点。按住左 `Shift` 输入大写字母不会切换，右 `Shift` 也不会切换。切回中文后，中文候选和先前保存的中文标点设置会恢复。

## 设置

选中墨流后，从输入菜单选择「打开设置」。设置自动保存。

- **外观**：调整候选词方向、数量和字号。
- **输入**：设置简拼、自动纠错、模糊音、Emoji、翻页键、特殊标点、英文标点和繁体输入。
- **个性化**：点击「添加」，填写输入码和短语，再点击「保存」。
- **词库**：检查并安装词库更新。下载需要联网，更新在当前输入结束后启用。
- **智能**：BYOK 智能预测服务，停顿约 0.5 秒后会出现建议，按 `Tab` 采纳；请求失败不影响普通输入。

## 数据与联网

用户词典、自定义短语和输入质量记录保存在 `~/Library/Application Support/InkFlow/`，不会上传；质量记录默认开启，可能包含输入内容、候选、选词结果及可获取的光标前文。词库更新会访问 GitHub。

「智能预测」默认关闭。开启后，墨流会把当前拼音、已选前缀及光标前后有限的文字发送给你配置的服务；服务如何处理数据及产生的费用由服务商决定。API Key 保存在本机钥匙串。墨流会在本地记录 AI 调用统计，并将建议使用的文字样本保留 30 天。

统计字段、保留规则和只读查询方法见 [AI 统计查询说明](macOS/AI_STATISTICS.md)。
