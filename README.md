# 墨流 InkFlow

本地运行的 macOS 拼音输入法，支持全拼、简拼、中英混输、Emoji 候选和简繁切换，并可自选服务开启 AI 输入建议。

需要 **Apple Silicon Mac，macOS 26 或更新版本**。

## 安装与启用

1. 从 [下载页面](https://github.com/nervouna/InkFlow/releases/latest) 下载并打开 `.dmg` 文件。
2. 在 Finder 按 `Shift + Command + G`，前往 `~/Library/Input Methods/`。若不存在，在 `~/Library/` 下新建 `Input Methods` 文件夹。
3. 将 `InkFlow.app` 复制到该文件夹，推出磁盘映像，然后注销并重新登录 Mac。
4. 打开「系统设置 → 键盘 → 文字输入 → 编辑」，点按 `+`，添加「墨流拼音」（英文系统为 **InkFlow Pinyin**）。
5. 从菜单栏输入菜单选择「墨流拼音」。输入 `nihao`，按空格选出「你好」。

## 日常输入

试试 `hulianwang`、`hlw` 或 `hulw` 输入「互联网」，`bs` 输入「不是」。中文模式中也能选择英文词和 Emoji；需要原样输入任意英文时，切换到英文模式。

| 操作 | 按键 |
| --- | --- |
| 选择候选 | 空格、候选旁的数字，或鼠标点击 |
| 上一页／下一页 | `[` / `]` 或 `Page Up` / `Page Down` |
| 删除正在输入的字母 | 退格 |
| 取消当前输入 | `Esc` |
| 提交原始输入字母 | 回车 |
| 切换中文／英文 | `Control + Shift + Space` |

输入菜单也可切换中英文，并勾选「英文标点」或「繁体输入」。正在输入时，更改会在本次输入完成或取消后生效。

## 设置

选中墨流后，从输入菜单选择「打开设置」。设置自动保存。

- **外观**：调整候选词方向、数量和字号。
- **输入**：简拼、自动纠错和 Emoji 默认开启，模糊音默认关闭。可在 `[]` 与 `-=` 中选择一组翻页键，调整特殊标点映射，或开启英文标点、繁体输入。英文标点会暂停特殊映射；繁体输入保留自定义短语原文。输入偏好在本次输入完成或取消后生效。
- **个性化**：点击「添加」，输入码填 `dz`、短语填「台北市信义区」，点击「保存」。以后输入完整的 `dz` 即可优先选出地址。输入码使用英文字母，短语需为单行文字；修改在当前输入结束后生效。
- **词库**：点击「检查词库更新」，发现更新后点击「下载并更新」。更新需要联网，并在所有正在进行的输入结束后启用；部分内置词条随应用更新。

## 更新应用

切换到其他输入法并保存工作，备份 `~/Library/Input Methods/InkFlow.app`，再用新下载的 `.dmg` 中的应用替换。注销并重新登录即可，无需重新添加输入源。若提示应用正在使用，先注销，再用其他输入法登录后替换。

保留 `~/Library/Application Support/InkFlow` 中的用户词典和数据。

上述词典前文重排完全离线，只临时读取插入点或当前组合前的一小段文字，不保存或发送这段文档前文。系统启用安全键盘输入时不读取前文。数字、点击、空格和结束组合仍对应屏幕上的候选；回车保留原有的原始拼音提交行为。

在设置的「智能」分类中填写 Base URL、API Key 和模型名称，保存后可开启「智能预测」。三个配置都有值即可切换开关，无需先通过联网验证；输入源菜单中的「智能预测」与设置同步。功能默认关闭，API Key 保存在本机钥匙串。服务使用 OpenAI Chat Completions 兼容接口，例如 DeepSeek 的 Base URL 为 `https://api.deepseek.com`，模型名称为 `deepseek-v4-flash`。

开启后，候选窗口显示期间拼音输入停顿 0.5 秒，会将当前组合前后各至多约 256 个 UTF-16 单位的文字、拼音及已选组合前缀发送给所配置的服务。翻页和移动候选高亮不会推迟请求或重复调用。AI 建议显示在候选窗口旁，不抢焦点；按 Tab 采纳，替换当前未上屏组合，保留前后已上屏文本。AI 只转换当前拼音，允许简拼、未完成音节和有限纠错，不续写或扩写。采纳后，能够确定读音的词语会进入现有本地词库学习，后续关闭 AI 也可使用；纠错按正确读音学习，不把手误注册为词码。仅在读音无法确定时跳过学习，上屏不受影响。过长建议会标注「部分显示」，Tab 采纳完整内容。空格、数字与点击仍选择普通候选。

继续输入、移动文档选区、关闭候选窗口或切换输入源会使旧建议失效。系统启用安全键盘输入时不请求建议；应用无法提供文档文字时使用空上下文。请求失败不影响普通输入，可在「智能」设置查看最近的调用错误。使用 AI 时会自动记录本地调用统计，并将此次已经使用的有限上下文、拼音、已选前缀、当前页普通候选及返回建议保存为 30 天样本，详见下文。上下文、建议及 API Key 不写入诊断日志，API Key 也不写入统计库。发送后的数据处理及调用费用由用户所选服务决定。

## 本地数据

日常输入离线完成。用户词典、自定义短语和输入质量记录均保存在本机，不会上传。质量记录默认开启，包括输入内容、候选、选词结果及可获取的光标前文。

数据目录是 `~/Library/Application Support/InkFlow/`。普通输入记录位于 `quality.sqlite3`，新增按键类别、相邻按键间隔、最后编辑后的等待时间和观测到的候选可见时长；未采集到的字段保持未知。AI 调用统计单独位于 `ai-statistics.sqlite3`，保留请求、返回、展示、插入调用、服务返回的 token 用量和可计算的费用估算。两者通过实际记录的组合 ID 关联。

AI 文字样本从该次建议调度开始保留 30 天，届满后删除文字，数值统计继续保留。清理在墨流进程启动及运行期间约每 30 秒执行，进程未运行时不保证按时删除；只读查询也会隐藏已过期但尚未清理的样本。**这项 30 天策略只作用于 AI 样本，不会追溯删除普通 `quality.sqlite3` 已保存的输入、候选和前文。** 统计不会额外读取文档内容。AI 统计随功能使用自动采集，目前没有独立采集开关或设置内统计页面，关闭「智能预测」后不再调度新建议；原有 0.5 秒触发策略不变。

在仓库目录中可用以下只读命令查看统计，默认覆盖所有已保存历史；`list` 默认只列最近 50 次，不输出文字，`inspect` 才展示指定 ID 尚未过期的样本：

```sh
python_bin=$(mise which python)
"$python_bin" macOS/Tools/ai-statistics.py summary --format json
"$python_bin" macOS/Tools/ai-statistics.py list --limit 20 --format json
"$python_bin" macOS/Tools/ai-statistics.py inspect ATTEMPT_ID --format json
"$python_bin" .agents/skills/inkflow-quality-analysis/scripts/quality.py timing --format json
```

AI 命令支持 `--db`、`--since`（包含）、`--until`（不包含）、`--model`（请求的模型）、`--strategy` 和 `--app` 精确筛选。展示采纳率是「已展示且已发出插入调用的次数 / 展示次数」，请求转化率是「已开始网络请求且已发出插入调用的次数 / 网络请求次数」；分母为零时显示未知。插入调用不代表外部编辑器最终保留文本，观测到候选可见也不代表用户注意到它。P50/P95 带样本数及单位，按键来自输入法收到回调的时刻，可见状态名义上每 100 毫秒观测一次。

费用默认未知，不内置服务价格。如需估算，可在数据目录放置可选的 `ai-pricing.json`（版本 1、按服务地址与模型匹配），在下次墨流进程启动时读取；每次请求保存当时匹配的价格快照。各币种分别汇总，缺失或不完整用量、缺少价格、模型不匹配等会保留未知，不当成免费请求。单位采纳成本使用同币种全部费用已知请求的费用，除以这批请求中已展示且已发出插入调用的次数，包含未采纳请求的消耗。配置示例、字段定义及更多命令见 [AI 统计查询说明](macOS/AI_STATISTICS.md)，估算不等于服务商账单。
