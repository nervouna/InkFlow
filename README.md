# InkFlow

本地运行的 macOS 简体拼音输入法，使用 librime 和系统候选窗口。

运行需要 Apple Silicon Mac、macOS 26 或更新版本；构建需要支持 Swift 6.2 或更新版本的 Xcode 命令行工具。

## 构建与安装

```sh
macOS/scripts/build.sh
macOS/scripts/test.sh
macOS/scripts/check-bundle.sh
macOS/scripts/install.sh --debug
```

日常开发使用 `--debug` 本地临时签名，无需证书或签名服务器。构建保留调试符号，调试安装声明 `get-task-allow`，便于 LLDB 附加；最终签名移除此调试权限。最终安装使用：

```sh
INKFLOW_SIGN_IDENTITY='<Developer ID 证书 SHA1>' macOS/scripts/install.sh --developer-id
```

首次构建需要联网下载校验过的引擎和词典；安装后的输入与词典处理不需要联网。签名使用 Team `T7976FL2LP` 的 Developer ID Application 证书，使用前检查证书主体 OU。应用标识为 `io.damao.inputmethod.inkflow`。

安装位置为 `~/Library/Input Methods/InkFlow.app`。首次安装后，在系统设置 → 键盘 → 文本输入 → 编辑中添加墨流拼音（英文系统显示 InkFlow Pinyin），然后从输入菜单选择。注册检查不能代替这一步实际确认。

再次运行安装脚本会将旧应用归档到 `build/backups`，并在安装和注册成功后刷新当前用户的输入菜单。刷新会短暂关闭输入菜单，更新期间请暂停输入或切换输入源。若刷新失败，已安装的新版本会保留，可运行 `bash macOS/scripts/refresh-menu.sh` 重试。菜单刷新只用于加载名称和图标，不代表输入法引擎已重启或功能验收通过。用户词典与部署数据保存在 `~/Library/Application Support/InkFlow`，安装不会删除它们。

若系统设置显示空白输入源，参见[调试说明](macOS/DEBUGGING.md)。

## 使用

- 输入全拼，用空格或数字 1–9 选词，也可以点击候选。
- 中文候选默认包含相关 emoji，例如 `weixiao` → 微笑、😊，`kafei` → 咖啡、☕，`aixin` → 爱心、❤️。原词保留在对应 emoji 前，沿用相同的选词和翻页方式。
- 预输入时支持常见声母倒序、声母重复和部分韵母倒序，例如 `hzidao` → “知道”、`nnihao` → “你好”、`tainqi` → “天气”。预输入保留原始字母，可继续编辑，选词后提交中文。
- 用 Page Up / Page Down 或 `[` / `]`、`-` / `=` 翻页。
- 退格删除，Escape 取消组合；回车或切换输入源结束当前组合。
- Control + Shift + Space 切换中文与英文，并先提交当前组合。
- Command、Option 等应用快捷键交给当前应用处理。

墨流会用插入点前的文字调整当前页候选顺序，例如前文为「准备午」时输入 `can`，可通过内置词典中的「午餐」优先显示「餐」。它只匹配跨越前文和候选的短语，使用词典词频决定次序；不理解整句含义，也不会把其他页的词移到当前页。为保留分段选词，只调整与原首选等长的候选；选定组合中的一段后，剩余候选沿用引擎排序。前文遇到标点、空白或应用不提供有效上下文时，保留引擎排序。

完整输入码命中自定义短语时，保留自定义短语的原有顺序，该次组合不做前文重排。

该功能完全离线，只临时读取插入点或当前组合前的一小段文字，不保存或发送这段文档前文。系统启用安全键盘输入时不读取前文。数字、点击、空格和结束组合仍对应屏幕上的候选；回车保留原有的原始拼音提交行为。

中文模式下，常用符号按以下键位输入：

| 按键 | 输出 |
|---|---|
| `{`、`}` | `「`、`」` |
| `[`、`]` | `【`、`】`，候选窗口打开时用于翻页 |
| `<`、`>` | `《`、`》` |
| 反斜杠 `\`、竖线键 | `、`、`｜` |
| 反引号、`~` | `·`、`～` |
| `$` | `¥` |
| `^`、`_` | `……`、`——` |
| 双引号、单引号 | 分别交替输入 `“` / `”`、`‘` / `’` |

每次引号按键只输入一边，单双引号独立轮换。拼音组词中的单引号仍用于分词，例如 `xi'an` 输入“西安”。小数和时间可继续输入 `3.14`、`10:30`。

引号轮换跟随当前输入会话，修改候选数量或自定义短语导致引擎组件重建时会从左引号重新开始；删除、移动光标和粘贴不会按文档内容修正轮换。英文模式下符号原样输入。

真实文本编辑器和浏览器输入体验需要在本机启用后验证。

第三方来源、固定版本与校验值见 [依赖说明](macOS/DEPENDENCIES.md)。

从输入菜单选择「打开设置」打开设置窗口。在「外观」中可选择候选词方向（水平／竖直）、数量（3–9）和字号（14／16／18／24／36），默认水平、5 个、14 号。设置自动保存；方向和字号即时应用，数量在当前组合结束后生效，保留正在输入的内容。「关于」显示应用与 librime 版本。

在「个性化」中可以添加自定义短语，选中条目后编辑或删除。例如将输入码设为 `dz`、短语设为「台北市信义区」，输入完整的 `dz` 后，该短语会优先出现在候选中，仍用原有的翻页、数字、空格或点击选词。

输入码只使用 a–z，大写字母会自动转为小写；短语不能为空，也不能包含换行、制表符或控制字符。输入码和短语两端的空白会去除。同一输入码可保存多个不同短语，按添加顺序显示；完全相同的条目不能重复添加。自定义短语保存在本机偏好设置中，增删改自动保存，并在当前组合结束后应用。

源码结构与开发验证见 [macOS 开发说明](macOS/DEVELOPMENT.md)。
