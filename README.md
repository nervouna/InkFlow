# 墨流 InkFlow

本地运行的 macOS 拼音输入法，支持全拼、简拼、中英混输、Emoji 候选、简繁切换和本机中文语音听写，也可自选开启 AI 输入建议与语音润色。

需要 **Apple Silicon Mac，macOS 26 或更新版本**。

## 安装与启用

安装已发布版本：

1. 从 [最新版本下载页面](https://github.com/nervouna/InkFlow/releases/latest) 下载 `InkFlow-<版本>-<构建号>-arm64.pkg`，双击打开并按提示安装。安装包经过签名和公证，只为当前用户安装到 `~/Library/Input Methods`，不需要管理员密码。
2. 首次安装：在「系统设置 → 键盘 → 文本输入 → 编辑」中添加「墨流拼音」（英文系统显示 InkFlow Pinyin），再从菜单栏输入菜单选择。

### 更新

已安装的墨流通过内置更新（Sparkle）升级，无需重新运行安装包。在「设置 → 更新」中可以开启每日检查，或点按「立即检查更新…」。

### 恢复

更新失败、墨流没有启动或安装中途被打断时，从[最新版本下载页面](https://github.com/nervouna/InkFlow/releases/latest)重新下载安装包并再次运行即可。安装包会先正常退出正在运行的墨流，替换应用后重新启动，并恢复原有的输入源设置。个人词库和设置保存在 `~/Library/Application Support/InkFlow/`，安装包不会改动。

### 卸载

1. 在「系统设置 → 键盘 → 文本输入 → 编辑」中移除「墨流拼音」。
2. 删除 `~/Library/Input Methods/InkFlow.app`；若墨流仍在运行，在「活动监视器」中退出它，或注销后重新登录。
3. 可选：删除 `~/Library/Application Support/InkFlow`。这会清除用户词典、自定义短语、设置和质量记录；如需保留，先在设置的「备份与恢复」中导出。
4. 清除安装记录：`pkgutil --volume ~ --forget io.damao.inputmethod.inkflow.pkg`。安装记录保存在 `~/Library/Receipts`，可先用 `pkgutil --volume ~ --pkgs` 确认记录存在。

源码开发、Developer ID 试用和正式发布流程见 [macOS 开发说明](macOS/DEVELOPMENT.md#workflows)。

## 日常输入

以下为默认按键。中英文切换与语音按键可在「快捷键」中修改；AI 建议固定使用 Tab 采纳。

| 操作 | 按键 |
| --- | --- |
| 选择候选 | 空格、候选旁的数字，或鼠标点击 |
| 上一页／下一页 | `[` / `]` 或 `Page Up` / `Page Down` |
| 删除正在输入的字母 | 退格 |
| 取消当前输入 | `Esc` |
| 原样提交正在输入的字母 | 回车 |
| 切换中文／英文 | 单击左 `Shift` |
| 按住说话 | 按住右 `Shift`，松开结束 |
| 连续听写 | 双击右 `Shift` 开始／结束，`Esc` 取消 |

## 设置

选中墨流后，从输入菜单选择「打开设置」。设置自动保存。

- **外观**：调整候选词方向、数量和字号，也可开启光标处的庆祝动效。
- **输入**：设置简拼、自动纠错、模糊音、Emoji、翻页键、特殊标点、英文标点和繁体输入。
- **快捷键**：设置中英文切换、标点切换、简繁切换和语音操作的快捷键；点击录制新的组合，可清除或恢复默认。
- **自定义短语**：点击「添加」，填写输入码和短语，再点击「保存」。
- **AI 服务**：保存 BYOK 服务配置；可开启智能预测、调整触发时延，按 `Tab` 采纳建议。
- **语音**：准备本机中文识别；可开启语音润色并配置共用的 AI 服务，失败时保留原文。
- **词库**：检查并安装词库更新。下载需要联网，更新在当前输入结束后启用。
- **更新**：可选择每日检查新版本；开启「自动下载并安装更新」后，墨流自动下载更新并在退出时安装。也可手动检查。

## 数据与联网

用户词典、自定义短语和输入质量记录保存在 `~/Library/Application Support/InkFlow/`，不会上传。

- **备份与恢复**：在设置的「备份与恢复」中导出或恢复个人数据（设置、快捷键、自定义短语、润色规则和学习数据）。恢复会替换而不是合并。备份不含 AI 配置、密钥和质量记录。文件含个人词语，请妥善保管。
- **质量记录**：默认只保存候选排名、操作时序（保留 28 天）和不含文本的学习效果事件（保留 90 天，最多 4,096 条），不保存任何输入文本。在「质量记录」中明确开启「同时保存输入文本」后，才会明文保存输入内容、候选和光标前文，同样保留 28 天；关闭时删除已保存的文本。可随时暂停或清除。数据库未加密，由 FileVault 和仅本用户可读的文件权限保护。
- **导出质量数据**：保存为 JSON，由你自行传递，不会自动上传。用法见 [质量数据导出](macOS/QUALITY-EXPORT.md)。

词库更新和启用后的版本检查会访问 GitHub；自动下载的更新包保存在系统缓存中。

语音音频由 Apple 系统在本机识别，首次准备中文识别资源可能需要联网。「语音润色」默认关闭；开启后，只有本次转写文字会发送给你配置的服务，失败时仍使用本机识别原文。

## 词库来源与许可

墨流代码采用 Apache-2.0 许可。内置词库由以下公开数据生成，编译后仍沿用各自的许可：

- 白霜拼音 rime-frost、雾凇拼音 rime-ice（中文词库、Emoji 表、技术英语选词）：GPL-3.0
- rime-pinyin-simp 兼容词库与 OpenCC 简繁数据：Apache-2.0
- rime-easy-en 英文词库：LGPL-3.0
- wordfreq 英文词频快照：CC BY-SA 4.0

每个发布版本附带词库源码包 `InkFlow-<版本>-<构建号>-dictionary-source.tar.gz`，内含上游数据、墨流的修改与生成脚本、许可证全文，可在[发布页面](https://github.com/nervouna/InkFlow/releases)下载；「设置 → 关于」也提供链接。详见 [NOTICE](NOTICE)、[词库说明](macOS/DICTIONARIES.md) 和 [许可证文本](macOS/Licenses/)。

「智能预测」默认关闭。开启后，墨流会把当前拼音、已选前缀及光标前后有限的文字发送给你配置的服务；服务如何处理数据及产生的费用由服务商决定。API Key 保存在本机钥匙串。
