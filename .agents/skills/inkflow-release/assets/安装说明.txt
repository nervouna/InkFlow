墨流 InkFlow

需要 Apple Silicon Mac 和 macOS 26 或更新版本。

首次安装
1. 在 Finder 按 Shift + Command + G，前往 ~/Library/Input Methods/。
   如果该文件夹不存在，请在 ~/Library/ 下新建 Input Methods 文件夹。
2. 将本磁盘映像中的 InkFlow.app 复制到该文件夹。不要放进“应用程序”。
3. 推出磁盘映像，注销并重新登录 macOS。
4. 在系统设置 → 键盘 → 文本输入 → 编辑中添加“墨流拼音”
   （英文系统显示 InkFlow Pinyin），然后从输入菜单选择。

更新已有版本
1. 切换到其他输入法，保存正在编辑的内容。
2. 将 ~/Library/Input Methods/InkFlow.app 复制到其他位置留作备份。
3. 用本磁盘映像中的 InkFlow.app 替换该文件夹内的旧版本。
   如果系统提示应用正在使用，请先注销，再使用其他输入法登录后替换。
4. 注销并重新登录，选择墨流后检查实际输入。

更新不需要删除或重新添加输入源。请保留
~/Library/Application Support/InkFlow 中的用户词典和部署数据。
