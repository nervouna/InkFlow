# 0.9.0 更新说明草稿

发布时按 `.agents/skills/inkflow-release/assets/release-notes-template.md` 整理到 `build/public-release-notes.md`。

### 更新内容

- 质量记录默认不再保存任何输入文本，只保留候选排名、操作时序和学习效果事件。需要文本时，在「质量记录」中开启「同时保存输入文本」并确认。
- 智能预测的服务地址必须使用 https://；只有本机 Ollama（localhost、127.0.0.1、::1）仍可使用 http://。保存不合规地址时会提示。

### 升级提示

- 升级后首次启动时，墨流会删除本机质量数据库中此前保存的全部含文本记录（输入内容、候选、提交文本和前文），不等待 28 天到期；排名以外的学习效果事件保留。需要保留文本记录的，请在升级前导出质量数据。
- 已配置 http:// 非本机地址的智能预测会在下次请求时失败并提示配置无效，请改为 https:// 后重新保存。
