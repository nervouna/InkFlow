# Runtime dependencies

`macOS/scripts/dependencies.sh` pins source URLs and SHA-256 digests. Archives live only in ignored `build/deps`. Chinese dictionary sources are pinned in `Core/Sources/InkFlowDomain/DictionaryModels.swift`; see [Chinese dictionary generation](DICTIONARIES.md). English admission and mixed-input policy are in [the mixed-input rules](../.agents/skills/inkflow-mixed-input-maintenance/references/rules.md). License texts ship from `Licenses/`.

- **Sparkle 2.10.0**, pinned in `Package.resolved` (revision `eef1a539a373c1f1a320624b1130fc5de7b2e100`, binary checksum `17e28312b8e18ab7cdbbe09a6fb28cc55a5479ec6c371dbc07cdecd2a14fd959`). Used only by InkFlowApp. Releases add an app-only ZIP for Sparkle beside the Installer DMG; the pinned `generate_appcast` signs it with EdDSA and writes `appcast.xml` (no deltas). The public key is in Info.plist; the private key stays in the local Keychain account `io.damao.inputmethod.inkflow` and never enters source or release artifacts. The feed is the latest GitHub Release's `appcast.xml`.
- **librime 1.17.0**, revision `33e78140250125871856cdc5b42ddc6a5fcd3cd4`: official universal macOS binary, linking only system libraries. Plugins load from the sibling `rime-plugins` directory.
- **Native mixed decoder** (`InkFlowRimeNative`, C++17): compiled against headers from the same librime revision, its official dependency archive and Boost 1.89.0; no host Homebrew headers and no extra runtime dylib. Updating librime requires updating this matching header/ABI set.
- **librime-lua**: `rime-plugins/librime-lua.dylib` from the same librime archive, with Lua 5.4.8 embedded. No other plugins are bundled. `install.sh` signs both dylibs before the app.
- **rime-frost** `19167adfe67fcba2f65c336117557639ff254ddb`, **rime-ice** `fbb516b2786e4d5444383706d13c31c2e4d10c08` and **rime-pinyin-simp** `0c6861ef7420ee780270ca6d993d18d4101049d0`: Chinese dictionary sources (GPL-3.0, GPL-3.0, Apache-2.0). Exact files are in `DictionaryModels.swift`; releases attach them with the recipe as the dictionary source bundle (`scripts/dictionary-source-bundle.sh`, see [the distribution review](../Core/Portable/licenses.md)).
- **Technical English**: 104 spellings from rime-ice `en_ext` plus 18 InkFlow-maintained ones; see [`Core/Data/TECHNOLOGY.md`](../Core/Data/TECHNOLOGY.md).
- **rime-easy-en** `54a4a07289412efc54134092c0d945f895a71ed3`: the unmodified `easy_en.dict.yaml` stays in `build/deps` as generator input; the filtered English and mixed dictionaries ship in `Resources/Rime`. LGPL-3.0 plus incorporated GPL-3.0. Upstream Lua filters and weights are not used.
- **wordfreq 3.1.1**: the checked-in `Core/Data/english-wordfreq.tsv` snapshot (CC BY-SA 4.0); see [`Core/Data/README.md`](../Core/Data/README.md).
- **rime-ice emoji data** (`opencc/emoji.txt` at `fbb516b2786e4d5444383706d13c31c2e4d10c08`, GPL-3.0): the only fetched emoji table; `schemas/opencc/inkflow_emoji.json` uses it alone.
- **OpenCC 1.1.9** s2t data from [`556ed22496d650bd0b13b6c163be9814637970ae`](https://github.com/BYVoid/OpenCC/tree/556ed22496d650bd0b13b6c163be9814637970ae), the version pinned by this librime release (Apache-2.0). Unmodified `STPhrases.txt` (`17fece21a28f3db2dc32397abd73d21ae73261c3f295fa6a3fe64b5e8d8b554b`) and `STCharacters.txt` (`ed1d268e0ad028511dcf5b0089faed0a980ad332449ec11d481ceefde6879f41`) are vendored under `schemas/opencc`; `inkflow_s2t.json` uses text dictionaries instead of compiled ocd2.
- `schemas/inkflow_pinyin.schema.yaml` adapts the upstream schema to one full-pinyin mode without stroke reverse lookup or symbol presets. The translator keeps the logical name `pinyin_simp`.

Typo tolerance uses Rime [spelling algebra](https://github.com/rime/home/wiki/SpellingAlgebra) aliases. Rime's `enable_correction` is not used: in the pinned engine it is [only a nearby-key corrector](https://github.com/rime/librime/blob/33e78140250125871856cdc5b42ddc6a5fcd3cd4/src/rime/dict/corrector.cc#L281-L300).
