InkFlow Chinese dictionary sources and modifications

Rime Frost (白霜拼音), gaboolic and contributors, GPL-3.0:
https://github.com/gaboolic/rime-frost
Files: cn_dicts/8105.dict.yaml, cn_dicts/base.dict.yaml,
cn_dicts/ext.dict.yaml, cn_dicts_cell/idiom.dict.yaml.
See rime-frost.txt for the license.

Rime Ice (雾凇拼音), iDvel and contributors, GPL-3.0:
https://github.com/iDvel/rime-ice
Files: cn_dicts/base.dict.yaml, cn_dicts/ext.dict.yaml.
See rime-ice.txt for the license.

Rime pinyin_simp, Rime contributors; derived from Android PinyinIME,
Apache-2.0: https://github.com/rime/rime-pinyin-simp
See pinyin-simp.txt for the license.

InkFlow modifications: normalize explicitly supplied Pinyin whitespace, case and
ü/v; merge term/reading pairs in source priority; retain Frost weights; calibrate
new Ice and legacy entries to positive-weight Frost overlaps; apply reviewed
local corrections. No pronunciation generation or simplified/traditional conversion.

The bundled dictionary-manifest.json records exact commits, files (by catalog
identifier), source checksums, generation recipe and applied calibration. The
pinned legacy compatibility input is included as legacy-pinyin-simp.dict.yaml.
Source generation code is in Core/Sources/InkFlowDomain/DictionaryGenerator.swift and the
pinned source catalog is in Core/Sources/InkFlowDomain/DictionaryModels.swift.

Default-enabled domain additions:
- Rime Frost cn_dicts_cell/computer.dict.yaml and exthot.dict.yaml at the same
  Frost commit. Original numeric weights are retained only for missing pairs.
- InkFlow's own supplement, Core/config/chinese-overrides.tsv (Apache-2.0):
  curated technology and AI terms with explicit InkFlow readings and weights.
  Fourteen of these common-usage terms were first noticed in public hotword
  lists published by Sogou; InkFlow supplies their text, reading and weight
  itself and copies no row, weight or file from those lists. Treating single
  common terms as not being a redistribution of that dictionary data is
  InkFlow's judgment, not an authorization verified with Sogou.

Removed data: before recipe 3, InkFlow also merged alswl/rime-selected's
conversion of Sogou dictionary 15117 (10,300 term/reading pairs). The original
redistribution authorization for that data was never verified, so the source
was removed from the catalog; the 3,975 pairs unique to it (all weight 1) are
no longer generated or shipped. No other Sogou-derived file is an input.

Chinese update checks follow the pinned paths in the Frost and Ice repositories.
The small curated Chinese/English vocabulary is updated with the application.

Corresponding source: each release attaches
InkFlow-<version>-<build>-dictionary-source.tar.gz with the verified pinned
upstream inputs listed above, the rime-pinyin-simp and rime-easy-en archives,
the Rime Ice emoji table, InkFlow's generator, catalog, corrections, data
snapshots and preparation scripts at the release commit, and these license
texts. macOS/scripts/dictionary-source-bundle.sh builds it.
